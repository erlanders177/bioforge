Qué hace

Varias herramientas de bioinformática reunidas en un motor ligero.

Secuencias

Explora FASTA/FASTQ y traduce ADN → proteína, codón a codón.

📊

Calidad

⚗️

Alinear

Compara dos secuencias y ve sus mutaciones resaltadas.

〜

Nanoporo

Señal eléctrica cruda (POD5/FAST5) → bases de ADN, desde cero, NumPy puro.

🔮

Evolución

⬇ Descargar (Windows .exe)
  1. Descarga el BioForge-…-windows.zip de la última Release.
  2. Descomprímelo donde quieras.
  3. Abre BioForge.exe. Nada que instalar.

Paquete de Python

Para quien programa, en Windows/Linux/macOS.

pip install bioforge

¿Quieres la app desde el paquete? Instala el extra y lanza el comando:

pip install "bioforge[app]"
bioforge-app

Hecho con honestidad

BioForge busca ser competitivo con las herramientas de un solo uso y único al combinarlas — no vender humo. Cada número está medido y los límites se dicen claros: por ejemplo, el basecaller de nanoporo hecho desde cero llega al ~74% en señal R9.4 real, honestamente por debajo del ~99% de las herramientas neuronales. Mira los benchmarks y todo el código en GitHub.
