Analyze DNA on your own computer

BioForge is a fast, offline bioinformatics engine — a desktop app for anyone, and a Python library for coders. No servers, no uploads, no accounts. Free & open source.

⬇ Download the app (Windows) ⌨ pip install bioforge
Windows · Linux · macOS · Python 3.10+ · one dependency (NumPy)

🖥️ Desktop app

🐍 Python library

What it does

Several bioinformatics tools bundled into one lightweight engine.

🧬

Sequences

Browse FASTA/FASTQ and translate DNA → protein, codon by codon.

📊

Quality

FastQC-style report: per-position quality, GC content, Phred scores.

⚗️

Align

Compare two sequences and see their mutations highlighted.

〜

Nanopore

Raw electrical signal (POD5/FAST5) → DNA bases, from scratch, pure NumPy.

🔮

Evolution

Rank which protein mutations may rise, and reality-check a specific one.

Get BioForge

Desktop app — no Python

For anyone. Just download and double-click.

⬇ Download (Windows .exe)
  1. Download the BioForge-…-windows.zip from the latest release.
  2. Unzip it anywhere.
  3. Run BioForge.exe. Nothing to install.

Python package

For developers, on Windows/Linux/macOS.

pip install bioforge

Want the desktop app from the package? Install the extra and run the command:

pip install "bioforge[app]"
bioforge-app

Built honestly

BioForge aims to be competitive with single-purpose tools and unique in combining them — not to oversell. Every number is measured, and the limits are stated plainly: for example, the from-scratch nanopore basecaller reaches ~74% on real R9.4 signal, honestly below the ~99% of neural tools. See the benchmarks and the full source on GitHub.
